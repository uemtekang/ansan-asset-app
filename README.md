# ansan-asset-app

안산영업소 창고 자산 관리 앱

## 프로젝트 소개
이 프로젝트는 안산영업소 창고 자산을 등록하고,
상태별로 조회하고,
추후 사진까지 함께 관리하기 위한 웹 앱입니다.

## 주요 기능
- 자산 등록
- 자산 상태 관리
- 대시보드 상태별 통계
- 검색/목록 조회
- 상태별 자산 필터 조회 예정
- 사진 업로드 및 표시 예정

## 상태 구분
- 전체
- 보관중
- 사용중
- 고장
- 불명

## 사용 기술
- React
- Vite
- Supabase
- Vercel

## 개발 목표
1. 대시보드에서 상태별 현황 확인
2. 상태 카드 클릭 시 해당 상태의 목록 조회
3. 보관중 자산 사진 표시
4. 모바일에서도 사용 가능한 UI 구성
